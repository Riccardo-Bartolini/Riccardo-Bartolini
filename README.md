# Riccardo Bartolini

**M.Sc. Cybersecurity Engineering student · Politecnico di Torino · Turin, Italy**

I am interested in application security, systems programming and the engineering decisions that make software reliable. My projects combine full-stack development with practical work on authentication, access control, relational databases and real-time scheduling.

I am pursuing an English-taught master's degree in Cybersecurity Engineering, following a B.Sc. in Computer Science and Engineering at the University of Bologna. I also completed a full-stack development internship at AREADATI, contributing to an existing production codebase under senior supervision.
